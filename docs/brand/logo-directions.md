# NARI Studio — Logo & Wordmark Directions (for selection)

Visual board: open [logo-directions.html](logo-directions.html) in a browser (it loads Manrope, Inter and Geist from Google Fonts for the comparison only; the site will self-host its font).

These are early sketches for choosing a direction. The chosen one is refined in Phase 2 (optical balance, 16/32 px versions, app-icon variant, clear-space and colour rules, SVG source).

| Direction | Idea | Character | Main risk |
|---|---|---|---|
| **A · Frame & Play** | Slide frame with a forward "play" shape | Literal, clear | Common video-app trope; doesn't carry the name |
| **B · Path N** *(recommended)* | An "N" drawn as one learner path, ending in a teal node (destination / completion) | Ownable monogram; branching & progress story | Monogram Ns are common, so the node and proportions must do the work |
| **C · Layers** | Three stacked slides stepping forward, front one teal | Calm, architectural | Stacked cards are used by many tools; weak at small sizes |
| **D · Wordmark-first "nari"** | Lowercase custom wordmark; "n" arch as symbol, teal dot | Friendly, modern | Familiar startup pattern; moves away from "NARI" caps |

**Why B:** it contains the initial (good for recall and app icons), tells a story that fits the product (a learner's path to completion, branching scenarios), stays legible at favicon size, and can later replace the default Tauri app icon so the app and the website share one identity.

Wordmark: "NARI" in Manrope 700–800 with slightly tight tracking, "Studio" in Manrope 500 in a secondary tone. All directions use ink `#0E1420` plus teal `#0F766E` / `#14B8A6`.

**Decision needed:** pick a direction (or combine, e.g. B's mark with D's lowercase wordmark).

Trademark note: before finalising, run a basic trademark/visual similarity search for "NARI" and the chosen mark in the classes for software (Nice class 9 and 42). That's an owner/legal task.
