# Phase 2 — Design system & Homepage: summary

Branch: `phase-2` · Date: 2026-11-20 · Status: **built, awaiting your review.** Phase 3 has not started.

## Decisions applied
| Decision | Applied as |
|---|---|
| Logo direction **D** (wordmark-first "nari.") | `Logo.astro` (text wordmark, Manrope 800, teal dot, small-caps "Studio"), `Mark.astro` (the "n" arch + dot, on an ink tile for icons), `public/favicon.svg`, favicon/apple-touch/512 PNGs and the Open Graph image, all generated by `npm run brand` |

| Astro + Tailwind + TypeScript | Astro 7.4, Tailwind 4.3, strict TS, `astro check` clean |

## What was built
- **Design system** — tokens in `src/styles/global.css` (colour with light and dark, type scale, radius, motion); components: Button (disabled links render as non-interactive text), StatusTag, SectionHeader, ProductFrame, Header with accessible mobile menu, Footer, BaseLayout (title, description, canonical, Open Graph/Twitter, JSON-LD `Organization` and `SoftwareApplication` with no price or rating). Internal reference at `/styleguide/` (noindex, excluded from the sitemap).
- **Config layer** — `site.ts` (unconfirmed contact/legal details are `null`), `navigation.ts` (links to pages not built yet fall back to homepage sections or are hidden, so there are no dead links), `features.ts` (every feature tagged Available / In development / Planned, sourced from the app's notes), `pricing.ts`.
- **Real screenshots** — `npm run capture` drives the app (browser mode, its own starter templates) and writes 11 images plus `manifest.json` (app v0.9.0). All images on the site are real captures; the learner views are cropped from the app's own Preview.
- **Homepage** — hero with the editor screenshot, benefits, 4-step workflow, four feature highlights with screenshots, capability overview with honest status tags, publishing, learner view, migration (with its limitations stated), audiences, plans, final CTA.
- **Early-access, 404, robots.txt, sitemap, security headers (`public/_headers`, CSP with `script-src 'self'`).**

## Not done / honest gaps
- **Not tested yet:** Firefox and Safari, keyboard-only pass, axe/Lighthouse run, screen reader (all Phase 5). Dark mode is implemented in tokens but not visually reviewed.
- Screenshots are small at full-width because the app UI is dense; Phase 3 can add cropped detail views.
- The Open Graph image shows the editor cropped at the right edge, deliberately, but is worth your eye.
- The logo is a first-pass vector built from direction D, not final artwork; no trademark search has been done.
- Image PNG fallbacks are emitted alongside AVIF/WebP and could be dropped to save build size.
- **GitHub push:** not done yet, see the end-of-turn note.
